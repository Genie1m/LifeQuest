# LifeQuest 基础设计系统

Step 2 · 2026-10-20。样式基准为 `src/app/globals.css`，仅覆盖应用布局与占位页面，不代表后续业务已实现。

| 项目 | 规范 |
| --- | --- |
| 视觉方向 | Modern Fantasy RPG + Gamified Productivity；墨绿背景、暖金操作、罗盘装饰、克制的纹章元素 |
| 色彩 | 背景 #101916，卡片 #19231f，正文 #ecece2，次级文字 #a5b1a7，主要操作 #d5b67a，错误 #f3b6a6，边框 #314038 |
| 字体 | 系统无衬线用于信息和操作；Georgia/系统中文衬线用于展示标题；无需请求外部字体 |
| 字号 | 展示标题 32–49px，页面标题 26–38px，区块标题 18–22px，正文 12–14px，辅助标签 9–11px；装饰英文最小 7px，不承担唯一信息 |
| 间距 | 基础 4px；常用 8/12/16/24/32/48px；主区域桌面左右 48px，移动 20px |
| 圆角 | 按钮 8px，状态/提示 12px，卡片 16px，主视觉 18px |
| 布局 | 248px 桌面侧栏，内容最大 1380px，78px 顶栏；三入口导航：冒险、目标、角色 |
| 断点 | 1100px 收紧侧栏和留白；800px 卡片变单列；600px 以下切为底部导航并保留安全区 |
| 操作 | 主按钮暖金底、次按钮描边、文本链接带方向提示；可交互目标至少 44px 高 |
| 状态 | loading 用 role=status，错误用 role=alert，并提供重读；空状态明确说明尚未实现和后续阶段 |
| 可访问性 | 当前导航 aria-current、跳到正文、键盘焦点、图标装饰 aria-hidden；支持 prefers-reduced-motion |
| 资源 | 罗盘由 CSS 构建，图标来自 Lucide；无游戏引擎、动画库或外部图片依赖 |

不显示占位 XP、等级、角色或任务。导航链接可用，占位功能不出现可误认为已执行的操作按钮。后续表单、对话框等按需扩充 shadcn/ui，不预装完整组件库。
