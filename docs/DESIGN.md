# LifeQuest 视觉与交互规范

## 设计方向

Modern Fantasy RPG与清晰的效率工具结合。人物建立冒险身份，靛紫界面组织信息，金色奖励强化真实行动后的成长反馈。

## 字体与布局

采用系统无衬线字体与中文回退；正文16px，输入16px，辅助文字至少12px。标题按页面、区域、卡片递减。布局基于4/8px间距；卡片圆角与留白保持一致，表单限制宽度，长计划自然滚动。

桌面使用侧栏，移动使用底部冒险、目标、角色三入口。390px左右留20px，320px留16px；底部预留导航与safe-area空间。输入和主要交互至少44px高。

## 人物与成长

三职业约3.5头身、三分之四视角、统一左上柔光，服装、道具和轮廓独立。创建页使用完整人物，首页使用独立头肩头像，角色页展示立绘与成长来源。[素材规范](CHARACTER_ART.md)

选择同时提供边框、文字和原生radio语义；图片contain显示，失败时保留输入并提供重试。角色轻动效可关闭，响应prefers-reduced-motion。

## 反馈与决策

- AI建议、未保存编辑和正式执行计划分别标示；接受建议后仍需保存与确认。
- 任务完成先展示标准并由用户确认，保存成功再显示XP和进度。
- 重规划用四步指引与单任务三种选择，内容变化、安排后移和时间预算分别解释。
- Loading使用status，错误使用alert与恢复入口。空状态提供下一步；导航用aria-current、选中色和指示条共同标记。
- 质量提示定位到具体任务，用户核对后自行修改，不把提示数量当评分。

响应式重点宽度为1440、390、320px。文字对比与控件焦点按可读性和键盘操作检查；实际样式和行为由组件及测试维护。
