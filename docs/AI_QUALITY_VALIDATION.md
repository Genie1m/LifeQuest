# AI质量验证方法

## 保持可比

固定60组输入、模型连接、Prompt、Schema、质量提示和评分锚点，运行前生成冻结清单。每次请求前核对源码指纹，响应核对服务端版本，错配时停止。新实验另建目录，原始记录不覆盖。

## 三层证据

| 证据 | 判断内容 |
| --- | --- |
| 自动回归 | 引用、范围保护、结构、过期响应、存储与XP规则 |
| 规则审计 | 长任务、估时说明、数量、实践周期、检查点等定位提示 |
| 内容评审 | 目标、基础、时间、行动、验收、阶段与可靠性7维评分 |

规则提示作为用户审核线索，不自动决定内容合格。长任务可能适合有经验用户；日历实践周期不能由总分钟下界代替。

## 记录与比较

首次请求、独立补跑和用户编辑分别标记。无输出的网络或超时不伪造结构结果；首次合格率保留全部请求分母。补跑采用最早合法计划，仍保留首次失败。

内容评分使用冻结的1至5分锚点与逐项证据，AI辅助与人工分开。先确定阈值，再读取结果。部分人工独立盲评检验评分一致性，未参与调优的新场景检验泛化。
