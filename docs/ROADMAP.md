# LifeQuest 产品路线

## 当前能力

| 能力 | 产品状态 | 核心验证 |
| --- | --- | --- |
| 角色与视觉身份 | 三职业独立立绘、头像与职业介绍 | 图片失败恢复、键盘选择与响应式 |
| 多目标管理 | 多草稿、最多3条活跃目标、1条重点、暂停与归档 | 状态隔离、名额与旧档兼容 |
| 成长路线 | 真实模型Adapter、手动与Mock规划、建议审核与编辑确认 | 结构引用、过期响应、草稿与正式计划边界 |
| 任务与成长 | 进展记录、明确完成、唯一XP结算、等级与成就 | 重复完成、保存失败、刷新恢复 |
| 计划调整 | 新预算、执行反馈、延期或后移选择、逐项差异与确认 | 已完成成果、XP与最终标准保全及修订后继续执行 |
| AI质量评估 | 固定60组输入、8项标准、版本冻结、独立补跑和Excel | 原始首次与补跑分开，AI辅助与人工评分分开 |

当前需求与规则见[PRD](PRD.md)，数据流见[ARCHITECTURE](ARCHITECTURE.md)，评测方法与产品改进见[评测案例](AI_EVALUATION_CASE_STUDY.md)。

## 后续优先级

1. **首轮生成可靠性**：诊断模型与中转超时，控制输出规模，使用固定输入对照延迟与质量。
2. **新手任务支架**：补必要前置与可运行小练习，联动核算任务时长、会话和周期；检查完整成果覆盖。
3. **人工复核与用户体验研究**：复核AI辅助评分，观察首次确认耗时、方案取舍和调整后恢复执行。
4. **面向公开体验的基础设施**：明确访问控制、费用与滥用防护后，再评估云端身份、数据库与多端同步。

角色外观拓展、收藏和章节叙事按实际用户反馈决定优先级，不替代当前执行与规划质量工作。每项后续开发单独确定范围和验收标准。
