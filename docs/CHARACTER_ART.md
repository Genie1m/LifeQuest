# 三职业人物与资源

人物由image_gen辅助生成，采用项目原创职业设定。三职业使用统一比例、三分之四视角与左上光照，完整服装和道具形成不同轮廓。

| 职业 | 视觉身份 | 个性 |
| --- | --- | --- |
| 知识法师 Scholar Mage | 紫蓝长袍、悬浮书本与法杖 | 沉静、好奇、热爱研究 |
| 探索游侠 Pathfinder | 绿色斗篷、背包、地图与指南针 | 勇敢、灵活、乐于尝试 |
| 创造工匠 Artificer | 工坊外套、护目镜、机械手套与蓝图 | 务实、热情、喜欢创造 |

职业用于身份表达，现实目标和成长方向由用户自主选择，奖励规则一致。当前展示基础外观，等级反馈通过界面与CSS动效呈现。

## 素材组织

- assets/characters/source保留人物母稿，服务后续再导出与来源追溯。
- public/characters提供透明WebP：全身480×600、768×960；头肩128×128、256×256。
- manifest.json记录来源哈希、裁切区域、显示尺寸与内容哈希文件名。
- 图片只含人物和道具，职业背景由CSS绘制；图片数据不写入业务快照。

运行 node scripts/export-character-art.mjs 使用sharp确定性裁切、缩放并编码，保留人物造型与真实alpha通道。运行时完整立绘与头像分别引用，避免用全身居中裁切替代头像。
